## Findings

Severity: blocker · critical · major · minor · suggestion. Status is updated at the end of the increment.

### F1 — Board rescales on almost every step · major · P3
- **Repro:** Binary search → press Next 6×, read `data-zoom` on the canvas.
- **Expected:** zoom stays put while stepping (only changes on lesson load, window resize, or when content would not fit).
- **Actual:** `1.00 1.00 1.18 1.03 1.00 1.18 1.18`. Every scale change moves everything on the board at once, which reads as a jerky transition.
- **Cause:** `fit(index === 0)` passes `onlyShrink` inverted, so steps ≥ 1 do a full refit (grow or shrink) and the transform snaps.
- **Fix:** pure `planFit` decision (refit only on load/resize; on step change shrink only if content overflows), and animate programmatic view changes.
- **Regression tests:** unit for `planFit`; E2E "zoom is stable while stepping".

### F2 — Tutor circles nothing on the "discard half" steps · major · P1
- **Repro:** Binary search → step 4 ("Discard the left half").
- **Expected:** ring around the moved `low` pointer and the note's arrow pointing at it.
- **Actual:** no ring, no arrow (`focus-ring` absent).
- **Cause:** engine focuses `ptr-low` / `ptr-high`; the renderer gives pointers `data-flip` but not `data-scene-id`, so the focus lookup fails silently.
- **Fix:** every id the schema accepts as a focus/arrow target gets `data-scene-id`.
- **Regression test:** E2E walks every step of all three lessons and asserts ring + arrow exist.

### F3 — Interrupted transitions teleport · major · P3
- **Repro:** step 3 → Next → after 150 ms Prev; sample `low` pointer per frame.
- **Expected:** pointer reverses smoothly from where it is.
- **Actual:** 130 px jump in one frame at the reversal. Spark chip: 59 px jump. Uninterrupted move also showed a 258 px single-frame jump (contribution of F1).
- **Cause:** FLIP "first" position is the previous *layout* position, not the current *visual* position; running animations are not cancelled before measuring.
- **Fix:** track each flight (from, to, start, duration); on a new step cancel running flips and start from the interpolated current position. Pure, unit-tested interpolation (`cubicBezier`, `positionAt`, `planFlip`).
- **Regression tests:** unit (interrupt, completion, reduced motion, determinism); E2E max per-frame jump below threshold for normal, interrupted and rapid navigation.

### F4 — Ring/arrow appear at the destination before the element arrives · minor · P3
- **Expected:** marker drawn once the focused element has settled.
- **Fix:** delay the draw-on by the flight duration when the focus element moved. Verify after F2/F3.

### F5 — No intuition before mechanics · major · P4
- **Actual:** every lesson starts with engine state ("Set up the search range"); no definition, why, analogy, preview or summary.
- **Fix:** typed teaching phases with a validated order; deterministic intro/summary content per capability; AI may write intro text but never states.

### F6 — Rate limit bypass via `X-Forwarded-For` · major · security
- **Repro:** 12 POSTs to `/api/lesson` with `X-Forwarded-For: 10.0.0.$i`.
- **Expected:** 11th+ request from one client is limited.
- **Actual:** 12/12 → 200. The limiter trusts the first, client-supplied XFF entry.
- **Fix:** derive the client key from platform-set headers first; add a global cap on live-AI calls that cannot be bypassed by spoofing. (Still per-instance; see ADR 0004.)
- **Regression tests:** unit for key derivation; route test for the global cap.

### F7 — Oversized chunked bodies are fully buffered · minor · security
- **Repro:** 2 MB chunked POST → server reads it all, then 400.
- **Fix:** stream the body with a 4 KB cap; 413 beyond it.

### F8 — No security headers; `X-Powered-By` exposed · minor · security
- **Fix:** `poweredByHeader: false`; `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options`/`frame-ancestors`, `Permissions-Policy`.

### F9 — Editor line numbers fail contrast · minor · a11y
- **Evidence:** axe `color-contrast` (serious) on line-number gutter in the Editor.
- **Fix:** lighter gutter colour. **Regression:** axe check in E2E for Canvas and Editor.
